# Фантазариум

Онлайн-игра на ассоциации по мотивам настольных игр этого жанра.

## Технологии

Backend: Python, FastAPI
База данных: SQLite
Frontend: HTML, CSS, JavaScript

## Возможности

- Регистрация и вход с хешированием паролей
- Игровые комнаты с кодом из 5 символов
- Раздача карточек, ассоциации, голосование
- Подсчёт очков, таблица результатов
- Живое обновление без перезагрузки страницы
- Адаптивная вёрстка для телефонов

## Запуск локально

    pip install -r requirements.txt
    uvicorn main:app --reload

Открыть http://localhost:8000
